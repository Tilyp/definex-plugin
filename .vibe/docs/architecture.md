## 分层设计

### 1. CLI 层 (cli.py)
- 命令行入口
- 参数解析与路由
- 用户交互

### 2. 业务编排层 (manager.py)
- 协调各组件
- 工作流编排
- 懒加载组件

### 3. 核心引擎层 (core/)
- **Scanner** - AST 扫描 + 缓存
- **Translator** - Python 类型 → JSON Schema
- **Validator** - 合规性审计
- **Watcher** - 文件监控 + 热重载
- **Builder** - 依赖隔离 + 打包

### 4. 运行时层 (runtime.py)
- 插件加载与执行
- 依赖注入 (sys.path)
- 流式响应处理

### 5. 协议适配层 (mcp_*.py)
- MCP 协议转换
- FastMCP 集成

### 6. 存储抽象层 (storage/)
- 策略模式实现
- 多存储后端支持
